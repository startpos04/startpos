## 🔧 Implementation Notes

### How Features Are Hidden

Features marked for v1.1 are hidden from users by adding their capability ID to `FUTURE_CAPABILITY_IDS` in:
```typescript
// web/src/lib/tutorial/feature-library.ts
const FUTURE_CAPABILITY_IDS = new Set([
  'LOYALTY_POINTS',
  'KITCHEN_DISPLAY',
  'DELIVERY_MANAGEMENT',
  'VIEW_ANALYTICS',      // Added 2026-08-25
  'ACCESS_API',          // Added 2026-08-25
])
```

This causes them to:
1. Show as "COMING_SOON" state in Feature Library
2. Not be recommended by BOS (Business Operating System)
3. Not appear as actionable items for users
4. Still exist in subscription plans for future activation

### Database Entries

All v1.1 features have:
- ✅ Feature records in database (via `features.csv`)
- ✅ Subscription plan entries (can be included in plans)
- ✅ Capability definitions (in capability-keys.ts)
- ❌ Implementation code (to be added in v1.1)

### Enabling a Feature for v1.0

To move a feature from v1.1 to v1.0:
1. Remove from `FUTURE_CAPABILITY_IDS` in `feature-library.ts`
2. Implement the feature functionality
3. Add capability definition to `capability-registry.ts` (if it needs BOS recommendations)
4. Update this roadmap document
5. Update release notes

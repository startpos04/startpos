# Pre-Print Checklist

Use this checklist before sending your calling cards to print. Completing these steps will ensure professional results and avoid costly reprints.

## ✅ Content Verification

### Text Accuracy
- [ ] Company name is spelled correctly: **StartPOS**
- [ ] Website URL is correct and active
- [ ] Email address is correct and monitored
- [ ] Phone number (if added) is correct
- [ ] All text is free of typos

### Visual Check
- [ ] Open `index.html` in Chrome
- [ ] Both front and back cards display correctly
- [ ] Colors look professional (not too bright or washed out)
- [ ] Text is readable at actual size
- [ ] No blurry or pixelated elements

## ✅ QR Code Validation

### Functionality
- [ ] QR code scans successfully on iPhone
- [ ] QR code scans successfully on Android
- [ ] QR code links to the correct URL
- [ ] Target URL loads quickly (< 3 seconds)
- [ ] Target page is mobile-friendly

### Quality
- [ ] QR code is sharp and clear (not blurry)
- [ ] QR code has adequate white space around it
- [ ] QR code is not too small (minimum 0.72 inches)

## ✅ Print Settings

### Chrome Print Dialog
- [ ] **Background graphics** is enabled (most important!)
- [ ] Paper size: Letter (8.5" × 11") or A4
- [ ] Orientation: Portrait
- [ ] Margins: Default
- [ ] Color: Color (not black & white)
- [ ] Scale: 100% (not "Fit to page")

### PDF Generation
- [ ] Save as PDF first (don't send HTML to printer)
- [ ] Open the PDF and verify colors
- [ ] Zoom to 200% and check text sharpness
- [ ] Background colors are visible (not white)

## ✅ Print Shop Communication

### File Preparation
- [ ] PDF is named clearly: `StartPOS-Calling-Card.pdf`
- [ ] PDF is under 10 MB (it should be < 1 MB)
- [ ] PDF opens correctly in Adobe Reader

### Specifications to Request
- [ ] **Size**: 3.5" × 2" (standard US business card)
- [ ] **Stock**: 300gsm or 350gsm card stock
- [ ] **Finish**: Matte (recommended) or gloss
- [ ] **Corners**: Rounded (7px / ~2mm radius)
- [ ] **Colors**: Full color / CMYK
- [ ] **Quantity**: Specify how many (e.g., 100, 250, 500)

### Questions to Ask
- [ ] Can they print with rounded corners?
- [ ] Do they offer matte laminate finish?
- [ ] What is the turnaround time?
- [ ] Can they provide a proof before printing bulk?
- [ ] What is the cost for your desired quantity?

## ✅ Test Print

### Before Bulk Order
- [ ] Request 1-2 test prints if possible
- [ ] Check that colors match your screen (roughly)
- [ ] Verify text is sharp and readable
- [ ] Confirm QR code scans after printing
- [ ] Check that corners are properly rounded
- [ ] Feel the card stock (should feel premium)

### If Test Print Has Issues
- [ ] Colors too bright → Request color correction / matte finish
- [ ] Colors too dark → Check "Background graphics" was enabled
- [ ] Text blurry → Ensure PDF was generated from Chrome, not screenshot
- [ ] QR doesn't scan → Regenerate QR code with higher contrast

## ✅ Final Approval

### Before Confirming Bulk Order
- [ ] Test print looks professional
- [ ] QR code scans reliably
- [ ] No typos discovered
- [ ] Contact information is current
- [ ] Price is acceptable
- [ ] Delivery timeline works for your needs

### Bulk Order
- [ ] Confirm quantity with printer
- [ ] Get written quote and timeline
- [ ] Provide clear delivery instructions
- [ ] Keep a copy of the order confirmation

## ✅ Post-Print

### Quality Check First Batch
- [ ] Scan QR codes on 5 random cards
- [ ] Check for color consistency across cards
- [ ] Look for printing defects (smudges, misalignments)
- [ ] Verify corners are rounded consistently

### Distribution Planning
- [ ] Store cards in a dry place
- [ ] Organize cards for easy access
- [ ] Brief team members on when/how to distribute
- [ ] Track which events/locations received cards

## 🚨 Common Mistakes to Avoid

❌ **Don't** send HTML files to printer — always use PDF  
❌ **Don't** screenshot the card — use Chrome's "Save as PDF"  
❌ **Don't** forget to enable "Background graphics"  
❌ **Don't** skip the test print — always verify first  
❌ **Don't** choose card stock under 300gsm — it will feel cheap  
❌ **Don't** print bulk without testing QR code after printing
